# OCS_EASTERN

OCS 东线作品的本地 Git 仓库。首个作品是《第三冬》。TFB、克里米亚、列宁格勒接入时，各用 `games/` 下的独立作品包。

| 路径 | 职责 |
|---|---|
| `packages/series` | OCS v4.3 公共规则。接收当前作品的数据，无作品专属规则或数据。 |
| `packages/match-core` | 与作品无关的命令版本、重复提交与对局记录。 |
| `games/third-winter` | 第三冬专规、剧本、资料导入和本作对局接点。 |

作品可依赖共享包，共享包之间按职责单向引用。仓库检查阻止共享包读入作品专规，以及作品直接引用其他作品。后续桌面客户端和联网服务通过对局命令接入。

开发环境为 Node.js 22.12 或以上。首次安装用 `npm ci`，全面检查用 `npm run check`。第三冬资料继续使用现有本机数据库，按[第三冬开发说明](games/third-winter/README.md)运行只读导入核对。斯摩棱斯克留在其独立的 Git 仓库。
