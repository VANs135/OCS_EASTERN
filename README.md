# OCS_EASTERN

OCS 东线作品的本地 Git 仓库。首个作品是《第三冬》。TFB、克里米亚、列宁格勒接入时，各用 `games/` 下的独立作品包。

| 路径 | 职责 |
|---|---|
| `packages/series` | OCS v4.3 公共规则。接收当前作品的数据，无作品专属规则或数据。 |
| `packages/match-core` | 与作品无关的命令版本、重复提交、对局记录和会话请求串行处理。 |
| `games/third-winter` | 第三冬专规、剧本、资料导入和本作对局接点。 |

作品可依赖共享包，共享包之间按职责单向引用。仓库检查阻止共享包读入作品专规，以及作品直接引用其他作品。后续桌面客户端和联网服务通过对局命令接入。

开发环境为 Node.js 22.12 或以上。首次安装用 `npm ci`，全面检查用 `npm run check`。仓库包含瓶中蝎结构化数据快照；本机完整数据库和地图/算子图片仍需单独准备。工程要求、模块边界、数据来源和开发进度见[第三冬工程交接](games/third-winter/docs/2026-11-22-第三冬工程交接.md)，运行方法见[第三冬开发说明](games/third-winter/README.md)。斯摩棱斯克留在其独立的 Git 仓库。
