# 瓶中蝎实库数据

本目录是《第三冬》剧本 8「瓶中蝎」运行与校准所用的结构化数据快照。这里只收录 JSON 数据，不含地图扫描图、辅助卡图片、算子图片、规则 PDF、存档或备份文件。

## 文件清单

- `map/`：瓶中蝎小地图六角格、格边及地图标定。
- `scenario/`：瓶中蝎开局初设与增援。
- `units/`：整理版第三冬陆军、苏军、空军和标记算子库。
- `tables/`：OCS 通规 v4.3 地面战斗、炮击和设施射击表的 JSON 导出。

这些文件来自项目方本机已校准资料库。地图格子与格边 JSON 保持游戏字段不变；格子库元数据里原有的 Windows 绝对路径已改为相对来源说明，避免公开仓库泄露本机目录信息。图表 JSON 从项目方持有的 OCS v4.3 图表 PDF 导出。

## 数据状态

格子库记录 374 个小地图六角格，格边库记录 1,045 条边。格边库的来源元数据当前包含 `river_state: pending`；接手人应保留此状态并在继续地图核对时复查，不要自行推断河流缺口。

## 本地程序所需的其他素材

本目录不包含地图原图、苏军辅助卡图片和算子图。桌面程序的完整实库窗口仍需项目方另行提供这些素材，以及 `地图标定/hex-calib-瓶中蝎.json` 以外可能需要的场景视觉资源。程序代码和数据加载路径见 `games/third-winter/desktop/local/data.mjs`。
