五条 P1 分别是：`pickIndex` 在 `size ≥ 2^32` 时 `limit=0` 导致 `while` 永不退出（死循环，非崩溃）；存档恢复对非 v1 版本硬拒绝、无迁移链，且 `cursor / turn / window / arrival` 完全未校验（`cursor: null` 也能进内存）；命令日志去重先于版本校验、回显历史 revision，且跨席位同一 id 不判重；`scorpion-retreat.ts:74` 用 `catch { return [] }` 把非法单位伪装成「无路可走」；以及 **`scorpion-arrivals.ts` 84 行 / 覆盖率 0%** ——正是 P0 的上游数据装配函数。
