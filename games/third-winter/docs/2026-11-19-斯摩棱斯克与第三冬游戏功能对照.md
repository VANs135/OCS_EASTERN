# 斯摩棱斯克与《第三冬·瓶中蝎》游戏功能对照

核对日期 2026-11-19。斯摩棱斯克工作树基线为 `eece60f`，另有正在编辑的地图和 Android 界面改动。瓶中蝎基线为 `f12e45a`。比较范围是玩家从选剧本、开局、对局到终局的体验，以及本机续局和联机交付。斯摩棱斯克提供操作流程与通规实现参考。第三冬的规则编号、原书数据、剧本裁定及地图和算子均以第三冬本作资料为准。

## 1. 当前完成度

- **斯摩棱斯克已有较完整的人类玩家操作链。** 七个正式剧本和维捷布斯克入门局均有配置；具备同机热座、单人自推、部分规则覆盖的人机对局、入门教学、可检索结算日志和本机存档。正式剧本的回归覆盖双方初设及至少一个完整回合，另有战役提前决胜和入门局自动走到终局的用例。[剧本库][S1] · [正式剧本流程用例][S2] · [入门局自对弈][S3]
- **瓶中蝎已能在 Windows 本机热座对局，主要规则已经接通。** 可进行初设、增援、地面移动、预备、补给、常用战斗与空军任务、逐枚战损与地图撤退，并自动存档。实库脚本已覆盖八回合终局、首次解冻提前结束、突然死亡；本轮重跑了 Windows 操作测试。完整八回合的验证范围是规则和对局命令，玩家只用桌面操作走完一整局仍待单独验收。[现有任务账][T1] · [完整对局脚本][T2] · [桌面验收入口][T3]
- **瓶中蝎的首要缺口是把已有效的规则命令转成完整玩家操作。** 优先补多机整备、联合射击、战斗补给来源与战后推进、补给分配、空军编组与混装空运，以及方面军炮击标记。普通拆分、整编、补员重建等需另核对原表、算子库存和剧本适用条件。互联网双人对局是 OCS_EASTERN 自己的交付项，两套工作树均无可供朋友入房联网的成品。[斯摩棱斯克对局形态][S4] · [第三冬对局入口][T4] · [共享命令记录][T5]

## 2. 从开局到终局的功能对照

“可操作”指正常玩家界面里有对应步骤。“规则已接”指会话接受该命令，有代码或用例可查，有些目前需高级命令。“待核”指仍需确认第三冬适用时机、剧本数据或实体库存。每行的结论既受功能范围影响，也受已验证用例的范围限制。

## 4. 参考实现的用法

- 复用“阶段 → 环节 → 动作”导航和命令入口的组织方式，用第三冬的规则判据生成可点击候选。左键负责选子、选格、选路和响应，右键呈现当前算子或目标格的复杂动作，辅助卡负责其实体标记。[斯摩棱斯克动作入口][S5] · [瓶中蝎预备与阶段动作][T7] · [瓶中蝎右键候选][T13]
- 胜负、随机数、规则账和两方权限放在对局层。地图、辅助卡和菜单只读取当前方可见的投影并提交命令。每个复杂动作写为独立模块，加对应的人机操作用例，以便后续各作品接入时沿用边界。[斯摩棱斯克会话环节][S6] · [第三冬会话命令][T4] · [共享命令记录][T5]
