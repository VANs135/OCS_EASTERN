## 5. 铁路轨距：这本书到底怎么写的

这是本轮最容易接错的地方。`TTW_Scenarios.pdf` 第 1 页不是“东/北半图一律苏军宽轨”，而是按 Railhead 命名铁路段，再由 `Wrong Gauge Markers` 标出德军轨距段。

### 5.1 Soviet Railheads 原文要点

- Map D：
  - `D55.05`、`D55.09`：`D62.06→D55.05`、`D62.06→D55.09` 为苏军宽轨，`D55.05—D55.09` 之间也为宽轨。
  - `D51.21`：宽轨回到 `D62.19`。
  - `D55.26`：宽轨回到 `D62.27`。
- Map B：
  - `B46.03`：宽轨回到 `B51.02`，再经 `D59.29`、`B57.07` 到地图边缘，包括 `B59.29—B57.07` 之间。
  - `B32.18`：向北经 `B25.34`、向东经 `B48.16` 的铁路已换轨；**向南往 `B31.13` 的线没有换轨**。
  - `B16.28`：向东的铁路为苏军宽轨。
  - `B16.35`：只是地图边缘格。

### 5.2 Wrong Gauge Markers 原文要点

- `D57.01` 与 `D56.04`：两格之间的线为德军轨距。
- `D50.35`：从该格向西南的线为德军轨距。
- `B54.09`：从该点向西的线为德军轨距。
- `B20.28`：单独标出的德军轨距点。
- `B20.30` 与 `B18.35`：两格之间的线为德军轨距。

### 5.3 判读口径

1. Railhead 是端头/换轨参照点；“back to”是从端头回到书明边缘或点；“through”是路径经过；“line between”是两格之间的具体边。
2. 苏军宽轨覆盖书明段，以及从宽轨主段连续延伸、途中没有 Railhead / Wrong Gauge 换轨点的支线。
3. Wrong Gauge Marker 标的是具体德军轨距段，不是把整个 hex 的所有铁路都染成德轨。
4. 没有书明为宽轨、也没有接到宽轨主段的铁路，保持标准轨。

`B43.20` 的正确性来自第 2 条：它只经 `B44.19` 接到 `B48.16`/`B48.19` 一侧的宽轨主段，`B43.20→B48.16` 之间没有 Railhead 或 Wrong Gauge 标记，所以整条支线随主段为宽轨。旧实现只走“Railhead→书明端点”的最短路径，漏掉了这条支线，才误判为标准轨。

### 5.4 当前实现的已知近似

- `dnieper-initial-gauge.ts` 已从书明端点的单路径改为 **B/D 东缘、B 北缘入口的铁路追踪**，并按同图幅、Railhead、Wrong Gauge 标记格、明确“未换轨”边截断。
- 当前 `WRONG_GAUGE_MARKERS` 仍按 **标记格**阻断，是保守近似。书里有些标记明确是“两格之间的线”（如 `D57.1—D56.4`、`B20.30—B18.35`），严格实现应细化到具体边，而不是整格阻断。
- `B46.03` 的书明路径写“through D59.29 and B57.07”，但地图库在 `B59.29` 无铁路；当前代码落到可核实的 `B51.2→B57.7`（经 `B56.6`）。这是已知源数据歧义，不要在不改数据说明的情况下悄悄改路径。
- `SOVIET_EDGE_ENTRIES` 目前是 01 的硬编码入口清单（`D62.6/19/27`、`B62.16/18/31`、`B24.35/37.35/41.35/42.35/55.35`）。若地图/剧本版本变动，先重新核对入口。
