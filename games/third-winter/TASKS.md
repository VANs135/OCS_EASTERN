# 《第三冬》研发任务清单

截至 2026-11-21 的引擎缺项、已有规则的操作缺口及资料待核项见[未完成机制清单](docs/2026-11-21-未完成机制清单.md)。本表部分组合待办包含已完成的子项，开发前按该盘点和代码核对。

当前优先完善规则引擎，先做到全景剧本可运行。旧档迁移和面向玩家的存档验收排在该里程碑之后。
开发期间验证单项机制和数据。全剧本测试由用户在最终阶段统一安排。

代码分工、规则窗口和全景接入顺序见[规则引擎模块化方案](docs/2026-11-21-规则引擎模块化方案.md)。

首个交付剧本为瓶中蝎（Scorpion）。验收目标是两名异地玩家在 Windows 安装版中完成初设、互相应答、断线续局和终局结算，并能用同一规则内核进行本地热座。

规则依据为 OCS v4.3 通规及图表、《第三冬》Living 专规和瓶中蝎剧本册、小地图。斯摩棱斯克仅作为通规实现参考。术语采用「射击」统称炮击、轰炸、低空扫射，overrun 为「突袭」，9.14d 为「延补队崩溃」。

## 已通过核验

- [x] 导入新版瓶中蝎地图数据库和整理版单位库。校验初设引用、飞机部署、固定与可变增援、入场格和边缘补给源。
- [x] 接通玩家回合顺序、天气与飞行条件、先手、胜利分和突然死亡判定。实库回归从部署推进至第 2 回合。
- [x] 接通普通地面移动、单算子燃料、预备堆叠、反应与扩张、追溯补给、断补损耗和部队储备恢复。
- [x] 接通正规战斗、突袭、炮兵对地和机场炮击，以及首回合苏军的两枚专属炮击标记。
- [x] 接通移动、战后推进和突袭进格时的补给堆、运输点与机场夺取。按用户裁定，幸存飞机可紧急位移到本方地图外空军盒。
- [x] 接通图上机场及地图外空军盒的飞机整备。用例验证付费、免费整备、激活容量、禁飞天气和 ZOC。
- [x] 接通基地转场与战斗机扫荡。按飞行条件、阶段、航程、苏军航空军分区检查起飞。扫荡进入双边空战并返航，转场进入敌方巡逻区时可被拦截并须检查防空。实库已验证飞机从空军盒起飞，在目标格显示、翻面及回盒。
- [x] 接通对地轰炸、机场轰炸和低空扫射。共用空战、拦截、防空、返航与地面射击结算，按剧本核对地图外起飞的短程修正。首回合实库演练苏军四枚飞机轰炸 `s17.04`，守军混乱，飞机回空军盒。
- [x] 接通运输破坏。设施表成功后放置标记，按敌方移动类别增加格内移动费并校验突袭门槛。实库验证标记在己方整理保留、敌方整理清除。铁路运力费用的通规已通过用例，瓶中蝎双方铁路运力均为零。
- [x] 接通地图外空军盒向图上友方机场的补给空运。补给从空军盒扣减，按加倍运力与机场卸载上限结算。实库第 2 回合已跑通增援入盒、装载、防空受损、卸载和返航。
- [x] 接通图上机场之间的补给空运。支持普通航程、半航程双倍运力、双倍航程留场，以及同阶段卸载补给的再次装运限制。受控实库盘面验证 He.111H 从 `s13.11` 向夺取后的 `s18.07` 运送 1T。
- [x] 接通战斗单位空运与补给混装。核对移动面、运输当量、起飞前和抵达后合计移动额度，运力受损时由所属方选择保留货物。受控实库盘面验证 Ju.52 运送德军 4-4-3 拆分团，并在卸载后继续移动。
- [x] 核对《第三冬》战斗单位空投资格。TTW 2.2d、3.2e 仅允许苏联第 1 近卫空降旅按预先规划空投，实库核验该旅的算子 ID 为 `4301`。
- [x] 接通预先空投计划、延期与取消、落地检定和损失。瓶中蝎实库在第 2 回合检验补给空投、地图显示及返航。空降旅未列入瓶中蝎编制，预先计划和落地使用受控盘面验证。
- [x] 接通编队、司令部与单算子燃料，以及运输点装载、卸载和移动中支用。瓶中蝎实库验证普通卡车从 `s5.16` 运送补给到 `s4.15`，第 5 近卫坦克军编内卡车用车载补给购买编队燃料。装载和燃料标记随盘面更新。
- [x] 接通同型运输点合并、拆分、普通延补队、追溯补给接力及延补队崩溃。轴心 20 MP 卡车延补队在 `s1.07` 的受控盘面验证原版算子翻面。
- [x] 开局战线只为铁路卸货格、补给源和剧本指定补给到达格确定控制，地面单位经过更新这些地点。轨距按格边，普通铁路格由战斗单位占据、控制区和轨距决定能否连通。读旧存档时忽略普通格控制。
- [x] 按用户裁定接通守方整堆具象战斗补给、多来源支付及逐枚使用部队储备。两枚各 1 RE 与单个多军力单位在只有 1T 时分别验证 12.10h 的保留和浪费。
- [x] 按 OCS 9.12f、9.14 接通撤退途中的特殊夺取。瓶中蝎在受控战果下验证部队经过 `s13.11` 自动夺取机场并继续撤退。
- [x] 按 OCS 16.0 和 TTW 1.1b 接通两级工事修筑、拆减、夺取与标记联动。验证夺取降级、易手、移除，以及等级参与战斗。
- [x] 按 TTW 2.4d 与瓶中蝎胜利条件接通 16-4-3 师损失、残部去向、两枚算子库存、胜利分及一步重建。实库用第 57 步兵师验证地图算子和死人堆联动。
- [x] 接通 TTW 通用事件 41–42 重掷算子，覆盖瓶中蝎适用骰组、持有方接力应答、续局和终局得分。实库第 2 回合验证增援补给重掷及桌面预览联动。
- [x] 用实库脚本从部署跑到终局，验证完整八回合、第 8 回合首次解冻提前结算和第 3 回合突然死亡。覆盖双方先手、解冻同步阶段、双方战斗损失和整理后读档标记联动。
- [x] 桌面预览按六角格分显示算子及其状态。回合、天气、飞行条件、胜利分、死人堆、离图空军和苏军炮击轨随局面联动。
- [x] 修正瓶中蝎小地图的格心与奇偶列错位。完整格以原图格心摆放，南北边缘裁切格在实际可见区域内居中缩放。
- [x] Windows 本地热座窗口已可启动，支持新建默认对局、从地图选单位和格子、开局部署、阶段推进、基础地面战斗与重掷应答。操作接入同一规则内核，实库验证自动存档和重开续局。
- [x] Windows 地图按左键选取、落位、选路和右键复杂动作操作。右键菜单按实际命中的算子或目标格生成，动作由第三冬规则引擎验证。阶段及待决应答保留在侧栏。
- [x] 按用户裁定将特殊夺取改为自动结算。实库验证移动经过机场时自动分配车辆与补给、位移飞机、继续移动，以及旧存档里的夺取应答自动恢复。
- [x] 接通普通战果的逐枚步损和地图撤退选路。实库验证行动值单位先扣步、同格参战堆叠逐格撤退，以及撤退途中经过机场自动夺取。
- [x] 新版第三冬算子库与指定的小地图数据库已接入本地窗口。实库验证零格战果可就地结算，并从苏军辅助卡点击实体炮击标记、选择中心格和提交方案。
- [x] 补给阶段可多选算子，查看各枚的抽象补给状态。对能使用同一补给堆或车载补给的待补算子，可一次确认具象补给并查看扣费与余量。
- [x] 地图和飞机整备使用左键逐枚点选，再点已选算子即取消。运输点拆合、货物分配、继续移动和残部营重建已接到右键菜单。
- [x] 用桌面操作入口自动完成固定种子的八回合整局。终局为苏军净胜利分 6 分平局，16 次整理后重开临时存档均恢复同一行动方和盘面。Windows 原生窗口回放 477 次界面操作，最终存档一致。战斗撤退、炮击标记回到恢复格及地图外飞机转场另用实库操作盘面验证。
- [x] 轴心和苏军离图卡、死人堆及回合天气卡接入同一对局状态。同格预备单位共用一枚实体标记，库内数量与地图同步。瓶中蝎 Kessel HQ 可由轴心离图盒入图、移除或战斗损失后按三回合回到可用盒。
